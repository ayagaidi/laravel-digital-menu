# Support

Thanks for using Laravel Digital Menu.

## Before asking for help

Please check the following first:

1. Read the setup instructions in `README.md`.
2. Confirm your PHP and Laravel requirements match the project.
3. Run `composer install` using the committed lock file.
4. Copy `.env.example` to `.env` and generate an application key.
5. Confirm your database exists and migrations complete successfully.
6. Search existing issues before opening a new one.

## Bug reports

Use the bug report template and include:

- steps to reproduce;
- expected and actual behavior;
- PHP version;
- Laravel/framework version from `composer show laravel/framework`;
- database driver;
- relevant logs with secrets and customer data removed.

## Feature requests

Feature ideas are welcome when they fit the project goal: a lightweight, bilingual, multi-branch digital menu starter for cafés and restaurants.

Describe the use case before proposing an implementation. This makes it easier to evaluate whether a feature belongs in the core project.

## Security issues

Do not open a public issue for vulnerabilities, leaked secrets, or sensitive data exposure. Follow `SECURITY.md` instead.

## What this project does not provide

This repository is maintained as an open-source project and does not include guaranteed response times, production hosting support, custom deployments, or private client implementation work.
