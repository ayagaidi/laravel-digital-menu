# Laravel Digital Menu v1.0.0

**Release date:** 2026-09-07

Laravel Digital Menu `v1.0.0` is the first stable open-source release of the project: a bilingual, multi-branch QR menu foundation for cafés and restaurants built with Laravel 12.

## What ships in v1.0.0

### Public menu

- Arabic and English content
- RTL / LTR-ready server-rendered views
- restaurant and branch routing
- branch-specific menu pages
- categories and menu items
- branch-level item availability
- price override support in the branch/menu-item pivot
- QR route per branch

### Administration

- session-based admin authentication
- disabled-account rejection
- branch management
- category management
- menu-item management
- dashboard summary counts

### Developer experience

- Laravel 12 / PHP 8.2+
- SQLite-friendly local setup
- environment-driven demo admin seeding
- Composer lock file for reproducible installs
- PHPUnit Feature Tests
- Laravel Pint style gate
- GitHub Actions CI on pushes and pull requests to `main`

### Open-source project experience

- English and Arabic READMEs
- architecture documentation
- public roadmap
- changelog
- security policy
- support guide
- contribution guide
- code of conduct
- bug and feature request templates
- pull request checklist
- public interface screenshots generated from the repository's demo views/data

## Quality status

The v1.0 foundation is protected by automated checks for application behavior and Laravel code style. The current suite covers public rendering, locale persistence, authentication, disabled users, branch availability, and inactive branch behavior.

## Security notes

- no demo password is committed
- `.env` is ignored
- demo admin credentials are supplied only through local environment variables
- the repository contains no client credentials, proprietary assets, production data, or private project branding

## Upgrade / installation

This is the first stable release, so there is no prior stable upgrade path.

For a fresh installation:

```bash
git clone https://github.com/ayagaidi/laravel-digital-menu.git
cd laravel-digital-menu
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```
